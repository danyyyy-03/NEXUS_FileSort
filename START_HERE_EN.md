# Quick start — NEXUS FileSort 0.2 (English)

1. Extract this folder, keeping the older v0.1 version separately.
2. Double-click **run.bat** to start the app.
3. To generate sample files: open this folder in File Explorer, click the address
   bar, type `cmd`, press Enter, then run `py -3.12 make_demo.py`.
4. In the app click **Choose Folder** and select `_TEST_FOLDER`.
5. Click **Preview Files** → **Organize Files** → **Undo Last Batch**.
6. In **Custom Rules**, enter `.pdf`, choose `Documents`, then click **Save Rule**.
7. In **History**, view previous moves. Use **Undo Last Batch** on the Organize tab
   when you need to restore the most recent batch.
8. To build the `.exe`, double-click **build.bat**. Open `dist\NEXUS_FileSort.exe`.

**Important:** Only test on copies. This is an early version, not a backup program.
Native drag-and-drop and a full Windows installer are not included yet.
